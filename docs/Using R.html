1  Using R

This book relies on the reader using R for both analyses and reporting. You can learn more about R and stay on top of recent developments by following https://www.r-project.org/. There are many introductory resources available for using R as an analytical tool. This book will take care of the “reporting” component with R.

The expectation is that you are familiar with three important R “components”:

  1. an interactive console
  2. a scripting environment
  3. helper packages

Figure 1.1 presents two components, the console and a script file. The script file has two elementary elements within it: 1) a comment line (identified by at least one octothorpe1), and 2) a command (2 + 2). The manner in which you access R is “up to you”. Many Psychology students like the R Studio interface (referred to as an “IDE” – Integrated Development Environment), but many options exist.

Any additional experience you may have with R is great, but if you understand the 3 critical components (as well as the specification of comments), have a positive attitude about R2, and follow the copy–paste format of this book, you should be fine.

Throughout this book, we will provide code that you can execute as example analyses – you can copy code that we provide and paste it into your local R session (and tweak/play with the code to better your own personal understanding of “what is happening”).

The code we share later in the book is a bit more elaborate, but the copy/paste process is the same regardless of how sophisticated the analytical content is (or isn’t).

1.1 Example Measure

If you follow the recommendations of this book, you will (eventually) produce your own unique measure and administer it to a sample of your choosing. However, before you do that, we will demonstrate Psychometric principles and practices utilizing a shared measure and dataset: the bfi from within the psych package.

Section 1.1 highlights important information about this dataset, primarily:

  1. What are the items?
  2. What are the scales?
  3. What are the scale definitions?3
  4. What demographics were collected?

The BFI dataset (from the psych R package) contains 2,800 responses to 28 variables. The 28 variables are presented in Table 1.1. The 2,800 responses are contained within the bfi object and will be used to demonstrate Psychometric analyses.
